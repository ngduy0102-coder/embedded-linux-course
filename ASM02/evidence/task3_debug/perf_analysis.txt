3. ANALYSIS

The Logger Thread has the largest observed call-graph contribution.
Floating-point formatting and log message generation are notable
areas for potential optimization.

The Alert Thread also contributes to processing overhead because
it formats and forwards alert messages.

The Processor Thread spends part of its execution waiting for
sensor data through the condition variable. This is expected
behavior and does not by itself indicate a performance problem.

The call-graph Children percentages include time in descendant
functions. They must not be added together as independent CPU
percentages.

4. LIMITATIONS

- Profiling was performed on the x86-64 host.
- sensor_thread_host.c was used instead of the ARM hardware driver.
- 236 samples were collected; results indicate observed activity
  but are not sufficient for precise micro-optimization conclusions.
- Results should not be interpreted as ARM target performance.
